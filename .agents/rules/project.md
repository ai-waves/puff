# Hollowdrift

This project's instructions for every coding agent are in @/AGENTS.md: commands, the definition of
done, the rules that keep the game working, and when to ask the user. Read `docs/STATUS.md` before you
start, and update it before you hand off (`docs/playbooks/handoff.md`).

The workflows in `.agents/workflows/` (`/verify`, `/playtest`, `/level-change`, `/new-mechanic`,
`/release-ios`, `/handoff`) run the step-by-step guides in `docs/playbooks/`.
